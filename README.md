# RailGuard

Interactive 3D Indian Railways departure safety demonstration. Select one or both hazards, run the AI safety scan, ask station staff to clear any detection, then confirm the train is ready to depart after a clear rescan.

## Run locally

Open `index.html` in a browser with an internet connection for the Three.js CDN scripts. The crowd recording is embedded in the HTML.

## Deploy on Vercel

Import this GitHub repository as a static site. No build command or environment variables are needed; deploy the repository root.

This is a simulation for demonstration purposes, not a certified safety system.
