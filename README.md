# RailGuard

Interactive 3D Indian Railways departure safety demonstration. Choose from person, passenger, and animal hazards. Run the AI safety scan; station staff automatically resolve detections and trigger a verification scan. Confirm departure after clearance. Sound controls include a synthesized horn and train-running audio.

## Run locally

Open `index.html` in a browser with an internet connection for the Three.js CDN scripts. The crowd recording is embedded in the HTML.

## Deploy on Vercel

Import this GitHub repository as a static site. No build command or environment variables are needed; deploy the repository root.

This is a simulation for demonstration purposes, not a certified safety system.
